# Lån til endring av eksisterende bolig (privat)

Klikkbar prototype av søknaden om lån til å oppgradere bolig for
privatpersoner, med endringene fra Miro-tavla «Oppstartsworkshop IG – Endring
lån til boligkvalitet», rammen «Lån til endring av eksisterende bolig
(privat)». Ren HTML, CSS og JavaScript, uten backend og uten byggesteg.

Publisert på <https://pettersommerseth1994.github.io/endring-bolig-privat/>.

## Kjør lokalt

```bash
python3 -m http.server 4321
```

Åpne så <http://localhost:4321/lan-oppgradere-bolig/>.

## Innhold

- `lan-oppgradere-bolig/` – prototypen. Se [lan-oppgradere-bolig/README.md](lan-oppgradere-bolig/README.md).
- `ds/` og `assets/css/hb-versjoner.css` – farger, typografi, fonter, logoer og
  versjonsboksen, kopiert fra husbanken-repoet.

Prototypen er bygget på `lan-miljovennlig-bolig` i husbanken-repoet (commit
9b87f55). De to kopiene synkes ikke.
